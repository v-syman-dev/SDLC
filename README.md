# Идеальный день

**Автор:** Сыман Владислав

**Дисциплина:** «Жизненный цикл разработки программного обеспечения»

**Вариант:** 29

## Описание проекта

«Идеальный день» — настольное приложение на языке Java с графическим интерфейсом на базе Swing. Проект предназначен для оценки того, насколько введённый пользователем режим дня близок к «идеальному», а также для формирования альтернативного расписания «для счастья».

Пользователь вводит время подъёма, продолжительность сна, работы и отдыха. На основе этих данных приложение:

- проверяет корректность введённых значений;
- рассчитывает интегральную оценку дня по шкале от 0 до 100;
- выводит вердикт и подсказку о самом слабом месте режима;
- предлагает альтернативное расписание, адаптированное к идеальным значениям и укладывающееся в 24 часа;
- сохраняет последние успешно обработанные параметры и подставляет их при повторном открытии окна ввода.
